# CANalyzer analysis workflow 
Scenarios: S1 nominal trace (periodicity, bus load, statistics); S2 timeout F02 (missing messages, gap in trace); S3 E2E faults F07 (counter/CRC anomalies via Python); S4 gateway routing (same payload on both buses, timestamp delta); S5 diagnostic traffic (filter 0x700-0x70D, P2 timing); S6 replay of a logged run.
